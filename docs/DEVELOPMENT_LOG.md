# HUMANLAB 開發歷程

這份文件整理整個專案從發想到上線的過程、關鍵決策與踩過的坑。

---

## 一、發想與定位

- **靈感來源**：參考「LearningCell 細胞結構工坊」的 UI 設計（米色手繪風、三欄版面）
- **目標**：做一個人體解剖版，使用者可透過 3D 模型探索人體構造
- **雙語**：英文（預設）＋繁體中文

## 二、需求演進

| 階段 | 內容 |
| --- | --- |
| 初期 | 8 個模型（全身、骨骼×2、心臟、胃、腦×2、頸） |
| 擴充 | 新增肺部（左右熱點） |
| 擴充 | 小腸拆分為「黏膜絨毛」「管壁」兩檢視 |
| 最終 | 11 個模型 |

## 三、技術選型

- **前端**：React 18 + Vite 5
- **3D**：Three.js + @react-three/fiber + @react-three/drei（與參考專案一致）
- **樣式**：純 CSS，沿用參考專案的設計系統變數（色票、圓角、陰影、Noto Sans/Serif SC + Caveat 字型）

## 四、核心功能實作

1. **三欄版面**：左側列表（人體／器官分類）、中間 3D 舞台、右側資訊面板
2. **3D 檢視器**：OrbitControls（旋轉、縮放、自動旋轉、復位視角）
3. **主畫面人體**：顯示型態切換（表面／骨骼／骨骼＋肌肉）
4. **熱點導航**：Blender 放 `hotspot_<器官>` 標記 → 匯出 GLB → 程式讀取節點位置 → 隱形可點擊（hover 顯示名稱）
5. **腦部角度判斷**：點腦部熱點時，依人體旋轉角度決定跳矢狀或冠狀切面
6. **多檢視切換**：腦部（矢狀／冠狀）、小腸（黏膜絨毛／管壁）右上角切換按鈕
7. **歡迎畫面**：品牌 LOGO、標題、CTA，點擊淡出進入
8. **使用說明**：頂欄「About」按鈕 → modal
9. **無障礙**：動態 `<html lang>`、`:focus-visible`、語意標記

## 五、模型處理流程

```
Blender 建模
  → 放熱點標記（hotspot_*）
  → 減面（Decimate Ratio 0.5，150 萬 → 75 萬面）
  → 縮貼圖（4096 → 2048）
  → 匯出 GLB
  → 放入 public/models/
```

- 檔案從每個 74–90 MB、150 萬面，優化到 33–38 MB、75 萬面
- 全部 11 個模型總體積約 395 MB

## 六、效能優化

1. **模型快取**：切換部位不重複下載／解析
2. **延遲載入**：人體 3 個模型優先載入，器官背景依序載入
3. **環境光**：RoomEnvironment + PMREM，避免金屬度過高導致模型發黑

## 七、踩過的坑（Bug 紀錄）

| 問題 | 原因 | 解法 |
| --- | --- | --- |
| 白方塊 | Blender 場景殘留 Cube | 刪除 Cube 重新匯出 |
| 心臟熱點騰空 | 熱點名稱有殘留空白 → 比對失敗 → 掉回預設位置 | 名稱比對改為「剔除所有非英數字」 |
| 腦部切面對應相反 | 身體模型朝向與假設不符 | 交換角度判斷邏輯 |
| 模型發黑 | 材質金屬度（Metallic）＝1 | 程式強制 metalness=0 + 環境光 |
| 減面沒生效 | Decimate 修改器沒 Apply | 匯出前要 Apply |
| 骨骼匯出空檔 | 減面 Ratio 太低或沒選到物件 | 重新設定 Ratio 重匯 |

## 八、部署

- **平台**：GitHub Pages（免費、單檔上限 100 MB，符合模型尺寸）
- **方式**：GitHub Actions 自動部署（`push` 即觸發建置＋上線）
- **備註**：Cloudflare Pages 單檔上限 25 MiB，模型 33–38 MB 會超限，故選 GitHub Pages
- **網址**：https://huangsz-1222.github.io/humanlab/

## 九、維護方式

- **本機預覽**：雙擊 `啟動網站.bat`
- **更新部署**：雙擊 `更新網站.bat`（自動 git add/commit/push）
- **新增模型**：照「模型上架流程」（見 README）

## 十、後續優化（上線後的改進）

| 改動 | 結果 |
| --- | --- |
| **模型再壓縮（gltf-transform）** | Draco 幾何壓縮 + WebP 貼圖 + 縮到 1024，394 MB → **24 MB**（1.4–3 MB／模型） |
| **載入速度** | 快了約 10–16 倍，模型 1～2 秒內載完 |
| **品牌 LOGO 壓縮** | 230 KB → 35 KB（256×256） |
| **左側載入進度條** | 每個模型項目顯示「待載入／載入中（含進度）／可互動」 |
| **移除佔位假模型** | 載入時不再顯示假人形／球體，改為乾淨背景 |
| **身體熱點保留** | 壓縮時用 resize+webp+draco（不跑 prune/flatten），避免熱點空節點被刪除 |

### 壓縮細節

- 用 `gltf-transform optimize`（Draco + WebP + 1024）處理無熱點的 10 個模型
- 身體（body_surface）因為有熱點空節點，改用 `resize + webp + draco` 個別指令，避免熱點被移除
- 貼圖從 PNG 轉成 WebP，幾何用 Draco 壓縮，面數再優化到 30–60 萬
