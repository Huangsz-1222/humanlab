# HUMANLAB 專案企畫書

人體解剖互動工坊 · Human Anatomy Interactive Workshop

---

## 一、專案概述

**HUMANLAB** 是一個雙語（English／繁體中文）的人體解剖 3D 互動學習網站。使用者可透過可旋轉、可縮放、可點擊跳轉的 3D 模型，探索人體各項器官與系統構造，並閱讀對應的教學內容（焦點、概念解讀、關鍵結構、趣味知識）。

- **線上網址**：https://huangsz-1222.github.io/humanlab/
- **專案性質**：個人教育／展示型網站
- **完成度**：核心功能已完成並上線

---

## 二、背景與動機

1. 傳統人體解剖教材多以**靜態圖片、平面圖表或影片**呈現，缺乏空間感與互動性。
2. **3D 互動模型**能讓使用者自由旋轉、放大、觀察，建立更直觀的空間理解。
3. 參考成功的互動學習案例「LearningCell 細胞結構工坊」，將同樣的「簡潔、現代、科技感」設計語言，應用到人體解剖主題。

## 六、內容規劃

### 6.1 模型清單（目前 11 個）

| 分類 | 模型 |
| --- | --- |
| 人體 | 全身表面、骨骼系統、骨骼＋肌肉、頸部 |
| 器官 | 心臟、肺部、胃部、腦部（矢狀／冠狀）、小腸（黏膜絨毛／管壁） |

### 6.2 教學內容結構

每個模型提供：
- **本節焦點**（Focus）：一句話說明重點
- **概念解讀**（Concept）：2～5 句的解剖說明，含數據與生活連結
- **關鍵結構**（Key Structures）：5 個重點結構＋簡短說明
- **趣味知識**（Fun Fact）：1 個有趣的事實
- **模型來源**（Source）：Blender JSON

## 七、技術架構

| 層面 | 技術 |
| --- | --- |
| 前端框架 | React 18 + Vite 5 |
| 3D 渲染 | Three.js + @react-three/fiber + @react-three/drei |
| 樣式 | 純 CSS（自訂設計系統變數） |
| 模型格式 | glTF Binary（.glb）＋ Draco 幾何壓縮 ＋ WebP 貼圖 |
| 部署 | GitHub Pages + GitHub Actions 自動部署 |

### 目錄結構

```
humanlab/
  index.html / vite.config.js / package.json
  docs/            ← 企畫書、設計、Blender 教學、開發歷程
  public/
    models/        ← 11 個壓縮後的 GLB 模型
    draco/         ← Draco 解碼器
    logo.png       ← 品牌 LOGO
  src/
    data/          ← models.js（清單）、content.js（內容）
    components/    ← Topbar、Sidebar、Stage、InfoPanel、SplashScreen、AboutModal
    viewer/        ← Viewer（3D）、modelLoader（載入＋快取＋狀態）
  .github/workflows/deploy.yml
  啟動網站.bat / 更新網站.bat
```

## 八、模型製作流程

```
Blender 建模
  → 放熱點標記（hotspot_<器官>）
  → 減面（Decimate Ratio 0.3～0.5）
  → 縮貼圖（2048）
  → 匯出 GLB
  → 壓縮（gltf-transform：Draco + WebP + 1024）
  → 放入 public/models/
```

- 原始每個模型 74–90 MB、150 萬面 → 優化後 1.4–3 MB、30–60 萬面
- 11 個模型總體積：約 800 MB → **24 MB**

## 十、部署方案

- **平台**：GitHub Pages（免費、單檔上限 100 MB）
- **方式**：GitHub Actions 自動部署（push 即觸發）
- **更新流程**：雙擊 `更新網站.bat`（自動 git add/commit/push）
- **備註**：Cloudflare Pages 單檔上限 25 MiB，原模型 33–38 MB 會超限，故選 GitHub Pages（壓縮後已無此限制）

## 十二、風險與挑戰

| 風險 | 影響 | 因應 |
| --- | --- | --- |
| 模型檔案過大 | 載入慢、記憶體高 | 已用 Draco＋WebP 壓縮至 24 MB |
| 瀏覽器相容性 | 部分裝置無法顯示 | 使用標準 glTF / WebP（現代瀏覽器皆支援） |
| 內容正確性 | 教學誤導 | 內容參考可靠解剖資料，定期校對 |
| 擴充成本 | 每個新器官需建模＋內容 | 建立標準化上架流程（見 README） |
