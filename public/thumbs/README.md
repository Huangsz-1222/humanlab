# 縮圖（可選）

把每個部位的縮圖 PNG 檔放在這裡，檔名用「英文小寫」對應：

| 檔名 | 對應部位 |
| --- | --- |
| `surface.png` | 全身（表面） |
| `skeleton.png` | 骨骼 |
| `skeleton_muscles.png` | 骨骼＋肌肉 |
| `neck.png` | 頸部 |
| `heart.png` | 心臟 |
| `stomach.png` | 胃部 |
| `brain_sagittal.png` | 腦部（矢狀剖面） |
| `brain_coronal.png` | 腦部（冠狀剖面） |
| `small_intestine.png` | 小腸 |

- 建議尺寸：約 **120×120 px** 的方形圖。
- 沒有放縮圖時，左側會自動顯示「色塊圖示」代替，不會出錯。
